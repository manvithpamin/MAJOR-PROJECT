About This Project

An intelligent herbal recommendation system combining tradition with technology

Project Overview

The Herbal Recommendation System is a major project that bridges the gap between traditional herbal medicine and modern sensor technology. It helps users discover appropriate herbal remedies based on their health conditions, enriched with data from electronic tongue analysis.

Objectives

📚 Knowledge Base

Build a comprehensive database of herbs, diseases, and their relationships based on Ayurvedic and modern pharmacological data.

🤖 Smart Recommendations

Provide intelligent herb recommendations mapped to specific diseases with dosage and preparation guidance.

👅 E-Tongue Integration

Leverage electronic tongue sensor data for objective taste profiling and improved herb matching accuracy.

🌐 Web Interface

Deliver an accessible, user-friendly web platform for exploring herbal remedies and analysis results.

Technology Stack

Backend Python, Flask
Database MySQL
Frontend HTML, CSS, JavaScript
Hardware Electronic Tongue Sensor Array

Methodology

  1. Collect and catalog herbal data from Ayurvedic texts and pharmacological databases
  2. Map herbs to diseases based on traditional and evidence-based relationships
  3. Profile herbs using electronic tongue sensor readings across six taste dimensions
  4. Build a recommendation engine that matches user conditions to optimal herbs
  5. Present results through an intuitive web-based interface
